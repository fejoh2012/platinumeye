# Texture Assets

`platinumeye-material-atlas.png` is a project-bound generated texture atlas created with the built-in Imagegen 2 image generation flow for this game pass.

The atlas is a 4 by 4 grid used by `src/main.js` for arena materials, water/ice, refinery metals, and weapon accents. The renderer keeps procedural canvas textures as fallbacks until the atlas finishes loading.
